┌─────────────────────────────────────────────────────────────────────────┐
│                         JAVASCRIPT FLOW                                 │
└─────────────────────────────────────────────────────────────────────────┘

USER CLICKS CATEGORY HEADER
         │
         ▼
toggleCategory(categoryId)
         │
         ├─ Find header row by data-category-id
         ├─ Find items row by id="items-{categoryId}"
         │
         ├─ Check if expanded
         │
         ├─ If EXPANDED:
         │    ├─ Remove 'expanded' class from header
         │    └─ Remove 'visible' class from items
         │
         └─ If COLLAPSED:
              ├─ Add 'expanded' class to header
              └─ Add 'visible' class to items


USER CLICKS "EXPAND ALL"
         │
         ▼
expandAllCategories()
         │
         ├─ Find all .category-header-row
         ├─ Find all .category-items-row
         │
         ├─ Add 'expanded' to all headers
         ├─ Add 'visible' to all items
         │
         └─ Change button text to "Collapse All"
              └─ Change onclick to collapseAllCategories()


┌─────────────────────────────────────────────────────────────────────────┐
│                         DATA FLOW                                       │
└─────────────────────────────────────────────────────────────────────────┘

DATABASE
   │
   ├─ Items with properties:
   │    ├─ item_name
   │    ├─ description
   │    ├─ property_number
   │    ├─ unit_value
   │    ├─ quantity
   │    └─ ...
   │
   ▼
PHP CONTROLLER (ReportController.php)
   │
   ├─ Fetch items from database
   ├─ Apply filters (office, classification)
   │
   ▼
PHP VIEW (inventory.php)
   │
   ├─ Check view_mode parameter
   │
   ├─ If 'expandable':
   │    ├─ Group items by category
   │    ├─ Calculate category totals
   │    ├─ Calculate grand total
   │    │
   │    └─ Render semi-expandable table:
   │         ├─ For each category:
   │         │    ├─ Render category header row
   │         │    ├─ Render category items row (hidden)
   │         │    │    └─ Nested table with items
   │         │    └─ Subtotal row
   │         │
   │         └─ Render grand total row
   │
   └─ If 'standard':
        └─ Render standard table
   │
   ▼
BROWSER
   │
   ├─ HTML rendered
   ├─ CSS applied
   ├─ JavaScript loaded
   │
   └─ User interaction:
        ├─ Click category header → toggleCategory()
        ├─ Click "Expand All" → expandAllCategories()
        └─ Click "Collapse All" → collapseAllCategories()

┌─────────────────────────────────────────────────────────────────────────┐
│                         CALCULATION FLOW                                │
└─────────────────────────────────────────────────────────────────────────┘

For Each Item:
   │
   ├─ Item Total = unit_value × quantity
   │
   └─ Add to Category Total

For Each Category:
   │
   ├─ Category Total = Sum of all item totals in category
   │
   └─ Display in category header and subtotal row

Grand Total:
   │
   └─ Sum of all Category Totals


┌─────────────────────────────────────────────────────────────────────────┐
│                         PRINT BEHAVIOR                                  │
└─────────────────────────────────────────────────────────────────────────┘

User clicks "Print Report"
   │
   ▼
Browser Print Dialog
   │
   ├─ CSS @media print rules applied:
   │    ├─ Hide filter controls
   │    ├─ Hide "Expand All" button
   │    ├─ Enhance borders for clarity
   │    └─ Adjust colors for B&W printing
   │
   └─ Current expand/collapse state preserved
        │
        ├─ If all collapsed: Print summary only
        ├─ If all expanded: Print full detail
        └─ If mixed: Print selected categories

                         QUICK REFERENCE

CSS Classes:
  .semi-expandable-table      - Main table
  .category-header-row        - Category header (clickable)
  .category-items-row         - Items container (hidden by default)
  .nested-items-table         - Inner table for items
  .category-subtotal-row      - Subtotal row
  .grand-total-row            - Grand total row
  .expand-all-btn             - Control button

JavaScript Functions:
  toggleCategory(id)          - Toggle single category
  expandAllCategories()       - Expand all
  collapseAllCategories()     - Collapse all

PHP Variables:
  $viewMode                   - 'standard' or 'expandable'
  $groupedItems               - Array of items grouped by category
  $grandTotal                 - Sum of all category totals
