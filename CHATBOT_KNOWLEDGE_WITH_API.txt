LGU INVENTORY SYSTEM - COMPLETE KNOWLEDGE WITH LIVE DATA API (Under 5000 chars)

=== SYSTEM ===
PHP inventory for Philippine LGUs. Tracks property, PAR/ICS forms, COA reports.
Tech: PHP 7.4+, MySQL, Vanilla JS. RESTful API, JSON responses.

=== LIVE DATA API ===
Base URL: http://localhost/lgu-inventory/api/chatbot.php
Access real-time database data for chatbot responses.

API ENDPOINTS:
1. GET ?action=summary → System stats (total items, by category/status, total value, offices count)
2. GET ?action=items&limit=50&category=SE&status=Active&office_id=1 → Property items with filters
3. GET ?action=offices → All offices with item counts and values
4. GET ?action=issuances&limit=50 → PAR/ICS records
5. GET ?action=returns&limit=50 → Return records
6. GET ?action=unserviceable → Damaged items
7. GET ?action=stats → Detailed statistics (items, issuances, returns, top offices)
8. GET ?action=search&q=laptop → Search items and issuances
9. POST {query: "How many items?"} → Natural language queries

NATURAL LANGUAGE QUERIES:
- "How many items?" → Count all items
- "How many offices?" → Count offices
- "What is the total value?" → Sum of all item values
- "How many unserviceable items?" → Count damaged items
- "How many PPE items?" → Count PPE category
- "How many SE items?" → Count Semi-Expendable

API RESPONSE FORMAT:
{success: true, data: {...}, message: "..."}

USAGE EXAMPLE:
fetch('api/chatbot.php?action=summary')
  .then(res => res.json())
  .then(data => console.log(data));

=== DATABASE ===
Tables: offices, property_items, issuance_records, return_records, unserviceable_records, disposal_records

property_items: id, property_number, description, category(SE/PPE), unit_value, quantity, office_id, status, condition_status, acquisition_date

=== BUSINESS RULES ===
- SE (Semi-Expendable): <₱50k → ICS form
- PPE (Property/Plant/Equipment): ≥₱50k → PAR form
- Property#: YYYY-[SE|PPE]-XXXXXX (e.g., 2025-PPE-000001)
- Status: Active→Issued→Returned/Unserviceable→Disposed
- PAR: Property Acknowledgement Receipt (for PPE, per person)
- ICS: Inventory Custodian Slip (for SE, per person)

=== CHATBOT INTEGRATION ===
Use API to get live data:
1. Summary: GET ?action=summary
2. Search: GET ?action=search&q=query
3. Ask: POST {query: "question"}

Example Integration:
async function getChatbotData(query) {
  // Try natural language first
  const res = await fetch('api/chatbot.php', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({query})
  });
  const data = await res.json();
  return data.answer || data.data;
}
