📖 Usage Examples for Chatbot

JavaScript Example:

// Get summary
fetch('api/chatbot.php?action=summary')
    .then(res => res.json())
    .then(data => console.log(data));

// Get items with filters
fetch('api/chatbot.php?action=items&category=PPE&limit=10')
    .then(res => res.json())
    .then(data => console.log(data));

// Search
fetch('api/chatbot.php?action=search&q=laptop')
    .then(res => res.json())
    .then(data => console.log(data));

// Natural language query
fetch('api/chatbot.php', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({query: 'How many items are there?'})
})
    .then(res => res.json())
    .then(data => console.log(data));

cURL Example:

# Get summary
curl "http://localhost/lgu-inventory/api/chatbot.php?action=summary"

# Get items
curl "http://localhost/lgu-inventory/api/chatbot.php?action=items&limit=5"

# Search
curl "http://localhost/lgu-inventory/api/chatbot.php?action=search&q=laptop"

# Natural language query
curl -X POST "http://localhost/lgu-inventory/api/chatbot.php" \
     -H "Content-Type: application/json" \
     -d '{"query":"How many items are there?"}'
