# RPCPPE Template Folder

Official **Report on the Physical Count of Property, Plant and Equipment**
workbook for the Municipality of Lumban, Laguna (GSO). The system fills this
exact file. It does not rebuild the COA layout in code.

The active file must be named **`rpcppe-template.xlsx`**.

Official tabs:

| Tab | Role |
|---|---|
| `LAND FINAL` | Land / infrastructure groups |
| `SUPPLIES AND EQUIPMENT FINAL` | Furniture, IT, machinery, etc. |
| `SEF SCHOOL BUILDING` | Special Education Fund buildings / equipment |
| `SEF OFFICE EQUIPMENT` | 2024 SEF office equipment (usually unused) |
| `LAND TITLE` | Land title schedule |
| `FORM` | Blank master — not printed |
| `IIRUP` | Different COA form — not filled |

Print physical count report: pick one tab to open the in-system form, or
**All tabs** to fill the official workbook.

The header prints once. Later pages continue the item rows (no repeated title block).
