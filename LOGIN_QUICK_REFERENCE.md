## 🐛 Troubleshooting

### Issue: 404 Error
**Fix:** Enable mod_rewrite in Apache

### Issue: CSS Not Loading
**Fix:** Clear browser cache (Ctrl + Shift + Delete)

### Issue: Can't Login
**Fix:** Run `setup-test-users.php` to create accounts

### Issue: Database Error
**Fix:** Import `database/lgu_inventory_system.sql`
