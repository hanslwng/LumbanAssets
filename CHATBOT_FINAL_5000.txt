=== LIVE DATA API (USE THIS TO GET REAL DATABASE DATA) ===
Base: http://localhost/lgu-inventory/api/chatbot.php

ENDPOINTS:
GET ?action=summary → Stats (total items, by category/status, value, offices)
GET ?action=items&limit=50&category=SE&status=Active → Items with filters
GET ?action=offices → Offices with counts
GET ?action=issuances&limit=50 → PAR/ICS records
GET ?action=returns → Return records
GET ?action=unserviceable → Damaged items
GET ?action=stats → Detailed statistics
GET ?action=search&q=laptop → Search
POST {query:"How many items?"} → Natural language

NATURAL LANGUAGE QUERIES:
"How many items?" "How many offices?" "What is total value?" "How many unserviceable?" "How many PPE?" "How many SE?"

USAGE:
fetch('api/chatbot.php?action=summary').then(r=>r.json()).then(d=>console.log(d))

RESPONSE: {success:true, data:{...}}

=== SYSTEM ===
PHP inventory for Philippine LGUs. Tracks property, PAR/ICS, COA reports.
Tech: PHP 7.4+, MySQL, Vanilla JS, RESTful API

=== BUSINESS RULES ===
SE (Semi-Expendable): <₱50k → ICS form
PPE (Property/Plant/Equipment): ≥₱50k → PAR form
Property#: YYYY-[SE|PPE]-XXXXXX (e.g., 2025-PPE-000001)
Status: Active→Issued→Returned/Unserviceable→Disposed
PAR: Property Acknowledgement Receipt (PPE, per person)
ICS: Inventory Custodian Slip (SE, per person)

=== DATABASE ===
Tables: offices, property_items, issuance_records, return_records, unserviceable_records, disposal_records
property_items: id, property_number, description, category, unit_value, quantity, office_id, status, condition_status, acquisition_date

=== CHATBOT INTEGRATION EXAMPLE ===
async function askInventory(query) {
  const res = await fetch('api/chatbot.php', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({query})
  });
  const data = await res.json();
  return data.answer || data.data;
}

// Get summary
const summary = await fetch('api/chatbot.php?action=summary').then(r=>r.json());

// Search
const results = await fetch('api/chatbot.php?action=search&q=laptop').then(r=>r.json());

// Get items
const items = await fetch('api/chatbot.php?action=items&category=PPE&limit=10').then(r=>r.json());
