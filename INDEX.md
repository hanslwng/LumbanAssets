## 🎯 QUICK ACTIONS

### I want to...

**Run the system**
```bash
1. Start Laragon
2. Create database: lgu_inventory
3. Import: database/schema.sql
4. Import: database/seed.sql
5. Open: http://localhost/GSO/public/
6. Login: admin@gso.local / password123
```

**Add my logo**
```bash
Replace: public/assets/logo.png
Size: 80x80 pixels
Format: PNG
```

**Change passwords**
```sql
UPDATE users 
SET password = '$2y$10$...' 
WHERE email = 'admin@gso.local';
```

**Add offices**
```sql
INSERT INTO offices (office_name, office_code) 
VALUES ('My Office', 'MO');
```

**Backup database**
```bash
mysqldump -u root lgu_inventory > backup.sql
```
