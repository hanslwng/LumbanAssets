LGU INVENTORY SYSTEM - ULTRA BRIEF (3000 chars)

OVERVIEW: PHP inventory for Philippine LGUs. Tracks property, PAR/ICS forms, COA reports.

STACK: PHP 7.4+, MySQL, Vanilla JS. RESTful API, JSON.

STRUCTURE:
- config.php: DB setup, helpers
- index.php: Main app
- api/: dashboard, items, offices, issuance, returns, unserviceable
- assets/: css/style.css, js/app.js
- includes/modals.php

DB TABLES:
1. offices: id, name, code
2. property_items: property_number, description, category, unit_value, quantity, office_id, status
3. issuance_records: form_type, form_number, property_item_id, issued_to
4. return_records: return_date, return_action, condition_on_return
5. unserviceable_records: marked_date, reason, disposal_status

RULES:
- SE (Semi-Expendable): <₱50k → ICS
- PPE (Property/Plant/Equipment): ≥₱50k → PAR
- Property#: YYYY-[SE|PPE]-XXXXXX
- Status: Active→Issued→Returned/Unserviceable→Disposed

API:
GET /api/dashboard.php → stats, recent data
GET /api/items.php?category=SE&status=Active
POST /api/items.php {description, unit_value, quantity, office_id}
POST /api/issuance.php {property_item_id, issued_to, form_number}
POST /api/returns.php {issuance_id, return_action, condition_on_return}
POST /api/unserviceable.php {property_item_id, reason}

FUNCTIONS:
- nav(page, event): Navigate
- loadDashboard(): Load stats
- openModal(id): Open dialog
- saveItem(): Create property
- liveClassify(): Auto SE/PPE
- apiGet/apiPost: API calls

PAGES: Dashboard, By Office, All Items, SE, PPE, Issuance, Returns, Unserviceable, Disposal, COA

MODALS: encode (add item), issue (PAR/ICS), return (transfer/unserv), unserv (mark damaged)

ISSUES:
1. Clicks fail: Check nav(page,event) param. Clear cache Ctrl+Shift+R
2. DB fail: Check config.php, import database.sql
3. CSS missing: Verify assets/css/style.css
4. API error: Check PHP logs

SECURITY: Prepared statements, input sanitization, foreign keys

CONFIG: DB_HOST, DB_USER, DB_PASS, DB_NAME, PPE_THRESHOLD=50000

WORKFLOWS:
- Encode: Click button→Enter data→Auto-classify→Generate#→Save
- Issue: Select item→Determine PAR/ICS→Enter recipient→Status="Issued"
- Return: Select issued→Choose action→Update status

SAMPLE: 10 offices (MAYOR, VMAY, ACCT, BUDG, TRES, ENGR, HLTH, SWDO, PLAN, GSO)

TEST FILES: test-connection.php, diagnose.html

INSTALL:
1. Import database.sql
2. Update config.php
3. Access http://localhost/lgu-inventory/

DEBUG: F12→Console (errors), F12→Network (API), Ctrl+Shift+R (refresh), diagnose.html

CSS: IBM Plex fonts, Sidebar 220px, Colors: ink/blue/green/red/amber

VERSION: v2.0, PHP 7.4+, MySQL 5.7+

KEY CONSTANTS:
- PPE_THRESHOLD: 50000
- Property format: YYYY-[SE|PPE]-XXXXXX
- PAR: Property Acknowledgement Receipt (PPE)
- ICS: Inventory Custodian Slip (SE)
- COA: Commission on Audit

COMMON FIXES:
- Clear cache: Ctrl+Shift+Delete
- Hard refresh: Ctrl+Shift+R
- Check event param in onclick="nav('page', event)"
- Verify assets/js/app.js line 82: case 'unserviceable' (not 'unserviceable')
- Import database.sql if tables missing
- Check config.php credentials if DB connection fails

HELPERS (config.php):
- getDBConnection(): Returns mysqli connection
- jsonResponse($data): Outputs JSON and exits
- sanitizeInput($data): Cleans user input
